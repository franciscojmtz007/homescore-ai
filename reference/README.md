# HomeScore AI Reference Models

This folder contains frozen reference models used to validate the HomeScore AI application.

## Model V1.0

HomeScore Model V1.0 is the baseline scoring methodology used for Prototype 1.

The reference spreadsheet documents and tests:

- Affordability scoring
- Location and lifestyle scoring
- Property scoring
- Hierarchical importance weighting
- Buyer-specific thresholds
- Constraint-aware recommendation grouping
- HomeScore calculation and ranking

The Python scoring engine should reproduce the results of this reference model before additional methodology changes are introduced.

Future model versions will be documented separately so that changes to the scoring methodology can be tracked and reproduced.
